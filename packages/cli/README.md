# Tack

Tack turns MCP servers, local TypeScript modules, and plugin bundles into
agent-friendly TypeScript tools.

Run Tack's stdio MCP server with a config file:

```sh
npx -y @cbxss/tack mcp --config /absolute/path/to/tack.config.json
```

See the [project README](https://github.com/shrimp-software/tack#readme) for
configuration, plugin, and development documentation.
